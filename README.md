# Dashboard nazionale Interpelli Chitarra AB55 / AB56

Monitoraggio dedicato alle classi di concorso AB55 e AB56, con archivio storico, filtri per regione/provincia e aggiornamento GitHub Actions orario.

## Installazione
1. Crea un repository GitHub pubblico.
2. Carica tutti i file di questa cartella mantenendo `.github/workflows/`.
3. In Settings > Pages scegli `GitHub Actions`.
4. In Actions abilita i workflow se richiesto.
5. Apri l'URL GitHub Pages indicato da GitHub.

## Nota sulla copertura
La struttura contiene tutte le regioni e le province italiane. Il crawler usa fonti web indicizzate/RSS e fonti istituzionali; non può garantire il rilevamento di ogni albo scolastico non indicizzato o protetto. Per una copertura ancora maggiore si possono aggiungere adattatori diretti per Albo Online/Amministrazione Trasparente e CMS scolastici.
